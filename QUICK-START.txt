SMART HIRE AI - MODULE 6

1. Extract this ZIP to a SHORT location such as C:\SmartHireAI or C:\SmartHireAIProject.
2. Open the SmartHireAI folder in VS Code.
3. Open PowerShell in that folder.
4. Run: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
5. Run: .\START-MODULE6-LOCAL.ps1
6. Open: http://127.0.0.1:5500

This package keeps Python runtime environments outside the project at C:\SmartHireAI_Runtime to avoid Windows long-path installation failures.
Do not store API keys in the ZIP. Set GEMINI_API_KEY in your local environment as needed.


SMART HIRE AI - ONE-COMMAND LOCAL START

From the SmartHireAI-UPDATED folder, run:
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  .\START-SMARTHIRE-ALL.ps1

The launcher uses local defaults (database smarthire, PostgreSQL user postgres/password postgres, JWT secret) and
starts the Spring Boot backend, CNN + other AI services, and frontend. Existing PostgreSQL is left running.
Open http://127.0.0.1:5500 after the launcher reports the stack status.
AI service isolation:
- Each AI service now runs from its own ai-services\<service>\.venv.
- This prevents NumPy/OpenCV/FastAPI version conflicts between CNN and Object Detection.
- Run REBUILD-AI-VENVS.cmd after upgrading the project or requirements files.
